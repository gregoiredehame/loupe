# Loupe

A layered image and PDF editor for Windows: layers, folders, masks, non destructive
adjustment layers, brushes, clone stamp, filters, PNG/JPEG/PDF export, printing,
multi-document tabs, dark themes, 8 languages.

## Download

- **Installer**: [LoupeSetup (latest)](../../releases/latest) - installs, associates `.lpd`
  files, and registers a clean uninstaller in Windows Settings.
- **Portable**: the `Loupe-<version>-win64.zip` file on the same page (unzip and run `Loupe.exe`).

The application checks for new versions from Help > Check for updates.
