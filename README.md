# Loupe

Un editeur d'images et de PDF pour Windows : calques, brushes, filtres, calques de reglage,
masques, exports PNG/JPEG/PDF, impression, multi-documents, interface sombre multilingue.

A layered image and PDF editor for Windows: layers, brushes, filters, adjustment layers,
masks, PNG/JPEG/PDF export, printing, multi-document tabs, dark multilingual interface.

## Telecharger / Download

- **Installateur / Installer** : [LoupeSetup (dernier / latest)](../../releases/latest)
- **Portable** : le fichier `Loupe-<version>-win64.zip` de la meme page (dezipper et lancer `Loupe.exe`)

L'application verifie les mises a jour via le menu Aide (Help > Check for updates).
